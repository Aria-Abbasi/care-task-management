# Care Task Management

A production-oriented care management system for caregivers, families, and healthcare professionals. The planned product includes a timeline-first caregiver dashboard, recurring tasks, medication schedules, health tracking, shift handovers, reports, notifications, and offline synchronization.

## Planned architecture

- Django REST API
- PostgreSQL
- Celery and Celery Beat
- Progressive Web App with offline support
- Role-based access for administrators, caregivers, doctors, and family members

## Status

Project setup and product design are in progress.
